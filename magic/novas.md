## Nova
A Nova is a physical shape of an Ether body or Ether mechanism. It mostly is called as "Magic Engine" or "Soul". It can be any entity which has a physical presence but can shift to Ether dimensions. Most of the time when people say "Nova", they mean the Novas which are attached to a concious body's spirit, called Hosted Nova. 

Hosted Novas can be extremely flexible to make. The functions and capabilities are not very deterministic. You can make an energy battery, or an orbital striker but the interface must sustain the architecture of the Nova. 

### Engine/Power Source
The most important part for Novas. Many Novas install an actual heavy duty engine, mostly a fuel based one which uses Ether mixed water or alcohol to run. Some advanced designs also include engines which take Ether and mix with any gas and combust it for raw power. But the best engine for this is said to be the Aranushiq Engine which directly converts Ether field disturbances to a specified type of energy through a complex method.

When the engine runs, it uses Ether based fuel to produce an Ether-like energy similar to electricity. This current is spread out through power grids placed within the Nova.

### Transponders
Then comes another component of these Novas called the Transponder. It is basically the remote control for the Nova. Transponders are mostly wireless, but some Novas use wires for best network. If the Nova is out of the user's Transponder's range, the Nova can't process signals. So an algorithm is set by the user for the Nova if it goes out of range. 

### Algorithms
Some Novas have extremely complex and compact algorithms, so they essentially dont even require a user to control them. 

### Electronics
Novas need many electronic parts for more complex things such as OS, microprocessors, memory units, network modules. They also need an interface to send signals back and forth to operate them, just like OS of a computer. This interface can be a runic interface or electronic one which is used in computers. Runic interfaces here are considered better option as they require less energy to operate, but can disrupt Ether intake of a Nova. 
Microprocessors depend on which type of Nova is being made. A basic combat Nova simply takes trained moves from memory and executes, scout Novas need more power to continuously see various patterns, or a utility Nova (modular engine, machinery, firearms or tools) barely needs a processor as the user directly controls it.
And then comes the DPU (Data Processing Unit), which is very rarely used. Only Novas which need absurd amount of memory or computation power need this kind of units. Like scout Novas, or a massive spell executor Nova as such.

### Sensors
Though this section should have been included in the electronics section, we exclude it from electronics as this may be very extensive.
Ether Radiometers measure ether radiation levels that is, which objects are generating Ether and how much. This device is usually not included in Novas as it consumes a lot of energy and is very electromagnetically noisy. 
Radars are only put in those Novas which need a robust defense or scanning capabilities. And radars too, like Ether radiometers consume more energy, but still many Novas have small versions of radars for safety.
Kanika Spectroscope is considered as the gospel for Nova users. It detects energy readings for different types of matters, like the regular matter, Ether fused matter, dark matter and such things. But this tool needs a lot of setup to run. It is very inefficient in power consumption, so it needs a power source separate from the main Engine. Then it needs a GPU (Graphics Processing Unit) to actually process what the Kanika Spectroscope is seeing. A microcontroller usually handles this entire system. The microcontroller, GPU, Kanika Spectroscope and the power source together is known as Pink Camera.

### Measurement devices
These devices are needed to do basic operation of Nova in physical space. These are small instruments which check the surroundings to keep the Nova in perfect condition.
Thermometers, Barometers, Ammeters, Voltmeters, Gyroscope, Ether-density-meter, etc. are needed for Novas which are used for serious physical applications like combat, exploration, heavy duty machinery, etc.

### Actuators
The parts that physically make a Nova to move, these include various mechanical components like motors, gearboxes, drivetrains, hydraulics, electric lines, etc.
Hydraulics are used for maximum power and precision, but these require several pumps to work which costs energy. Other cheaper options are Pneumonics which use compressed gases in place of liquids but they have less power and precision and can fail easily.
Other motors include the classical electric motors which requires relatively less setup unlike hydraulics but they draw more energy to increase power. So another alternatives of electric motors are used, PCB motors. These are highly efficient and require very less space. PCB motors dont produce much power but are considered best for nano-machinery.
